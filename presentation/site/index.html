Vues unifiées transverses

Les foreign tables sont exposées via des vues fédérées qui combinent les données des 3 SGBD comme si elles étaient locales.

Flux d'Accès aux Données via FDW

Les requêtes sont transparentes pour le Backend : PostgreSQL interroge les bases distantes à la volée via mysql_fdw et tds_fdw. Aucune duplication des données distantes.

🐳 Docker & Infrastructure (3 erreurs)

ERR-001 — Permission chmod dans le Dockerfile mssql-compta : USER mssql déclaré avant COPY/chmod → déplacé après.

ERR-003 — Ports 5432, 3306, 1433 occupés localement → mapping vers 5435, 3308, 1435.

ERR-005 — Résolution DNS entre conteneurs : réseau Docker différent après restart → docker compose down && up.

Résolu

🔗 FDW & Fédération (3 erreurs)

ERR-004 — Option dbname invalide pour mysql_fdw au niveau serveur → déplacée dans chaque FOREIGN TABLE.

ERR-009 — FDW non initialisés après restart → script post-init.sh en arrière-plan.

ERR-014 — Format de date tds_fdw Jan 10 2024 12:00:00:AM → colonnes en VARCHAR(30) + TO_DATE().

Critique Résolu

⚙️ Backend & Frontend (3 erreurs)

ERR-010 — pool_pre_ping incompatible avec asyncpg/aiomysql → retiré, health check via SELECT 1.

ERR-011 — Tests pytest async : asyncio_mode = auto manquant + fixtures non décorées → centralisé dans conftest.py.

ERR-013 — Frontend appelle sans préfixe /api → VITE_API_URL=http://localhost:8000/api.

Haute Résolu

💾 Données & Seed (5 erreurs)

ERR-002 — Trigger MySQL créé avant sa table → ordre inversé dans le script.

ERR-006 — ICF de 65 caractères pour CHAR(64) → troncature sed.

ERR-007 — Montant 0.00 viole CHECK(montant > 0) → remplacé par 1.00.

ERR-012 — Table transaction vide : auto-incrément désynchronisé → TRUNCATE ... RESTART IDENTITY.

ERR-015 — Violation PK plan_comptable (seed exécuté 2×) → ignoré via || true.

Résolu
